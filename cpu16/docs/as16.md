# as16 — CPU16 Assembler Rehberi

```sh
npm run cpu16 -- asm  program.s              # program.hex (Intel HEX, EEPROM programlayıcı için)
npm run cpu16 -- asm  program.s -o out.bin --list   # ham ikili + listeleme
npm run cpu16 -- run  program.s [--trace]    # emülatörde çalıştır (UART çıktısı konsola)
npm run cpu16 -- dis  out.bin                # geri çevir
```

## Sözdizimi

```asm
; yorum
SABIT = 0x40 << 8          ; veya: .equ SABIT, 0x4000
etiket: KOMUT op1, op2     ; komut adları büyük/küçük harf duyarsız, semboller duyarlı
```

- **Register'lar:** `r0`–`r7`, `sp` (= r6), `lr` (= r7).
- **Sayılar:** `42`, `0x2A`, `0b101010`, `'A'`, `'\n'`, alt çizgi ayırıcı `0xFF_00`.
- **İfadeler:** `+ - * / % << >> & ^ |`, parantez, tekli `- ~`, `$` (bulunulan adres), `lo(x)`, `hi(x)`.
- **Bellek operandı:** `[r1]`, `[r1+4]`, `[sp-2]`, `[r2+OFFSET*2]`.

## Komutlar

| Grup | Sözdizimi |
|---|---|
| ALU | `ADD ADC SUB SBC AND OR XOR rd, rs1, rs2` · `CMP rs1, rs2` |
| Tekli | `MOV NOT NEG SHL SHR SAR ROL ROR rd, rs` · `SXB rd, rs` |
| Sabit | `ADDI rd, rs, -32..31` · `SUBI rd, rs, n` · `CMPI rs, -256..255` · `LUI rd, 0..255` |
| Bellek | `LW/SW r, [rb±n]` · `LBU/SB r, [rb±n]` · `PUSH r` · `POP r` |
| Akış | `B hedef` · `BEQ BNE BCS BCC BMI BPL BVS BVC BHI BLS BGE BLT BGT BLE hedef` · `JAL/CALL hedef` · `JALR rd, rs, ofs` · `RET` |
| Sistem | `NOP HALT EI DI RETI SWI` |

**`LI rd, değer`** sözde komuttur: değer 0..255 bir sabitse tek `LI`, değilse `LI` (düşük bayt) + `LUI` (yüksek bayt) üretir. Değer henüz tanımlanmamış bir etiketse her zaman 2 komut ayrılır.

## Direktifler

| Direktif | Anlam |
|---|---|
| `.org adres` | yazma adresini değiştir |
| `.word a, b, ...` | 16 bit değerler (little-endian) |
| `.byte 1, "metin", 0xFF` | baytlar; string'ler bayt bayt |
| `.ascii "x"` / `.asciz "x"` | string (asciz sona 0 ekler) |
| `.space n [, dolgu]` | n bayt boşluk |
| `.align n` | adresi n'in katına yuvarla (komutlar çift adreste olmalı) |

Hatalar satır numarasıyla verilir; menzil dışı sabit, tek adreste komut, iki kez tanımlanan etiket ve uzak dallanma derleme hatasıdır.

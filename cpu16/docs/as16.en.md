# as16: CPU16 assembler guide

```sh
npm run cpu16 -- asm  program.s              # program.hex (Intel HEX, for the EEPROM programmer)
npm run cpu16 -- asm  program.s -o out.bin --list   # raw binary + listing
npm run cpu16 -- run  program.s [--trace]    # run in the emulator (UART output to the console)
npm run cpu16 -- dis  out.bin                # disassemble
```

## Syntax

```asm
; comment
SABIT = 0x40 << 8          ; or: .equ SABIT, 0x4000
etiket: KOMUT op1, op2     ; label: instruction. Mnemonics are case-insensitive, symbols case-sensitive
```

- **Registers:** `r0`–`r7`, `sp` (= r6), `lr` (= r7).
- **Numbers:** `42`, `0x2A`, `0b101010`, `'A'`, `'\n'`, underscore as a separator `0xFF_00`.
- **Expressions:** `+ - * / % << >> & ^ |`, parentheses, unary `- ~`, `$` (current address), `lo(x)`, `hi(x)`.
- **Memory operand:** `[r1]`, `[r1+4]`, `[sp-2]`, `[r2+OFFSET*2]`.

## Instructions

| Group | Syntax |
|---|---|
| ALU | `ADD ADC SUB SBC AND OR XOR rd, rs1, rs2` · `CMP rs1, rs2` |
| Unary | `MOV NOT NEG SHL SHR SAR ROL ROR rd, rs` · `SXB rd, rs` |
| Immediate | `ADDI rd, rs, -32..31` · `SUBI rd, rs, n` · `CMPI rs, -256..255` · `LUI rd, 0..255` |
| Memory | `LW/SW r, [rb±n]` · `LBU/SB r, [rb±n]` · `PUSH r` · `POP r` |
| Flow | `B hedef` · `BEQ BNE BCS BCC BMI BPL BVS BVC BHI BLS BGE BLT BGT BLE hedef` · `JAL/CALL hedef` · `JALR rd, rs, ofs` · `RET` |
| System | `NOP HALT EI DI RETI SWI` |

**`LI rd, değer`** is a pseudo-instruction. If the value is a constant in 0..255 it emits a single `LI`; otherwise it emits `LI` (low byte) + `LUI` (high byte). If the value is a label that is not defined yet, 2 instructions are always reserved.

## Directives

| Directive | Meaning |
|---|---|
| `.org adres` | change the output address |
| `.word a, b, ...` | 16-bit values (little-endian) |
| `.byte 1, "metin", 0xFF` | bytes; strings byte by byte |
| `.ascii "x"` / `.asciz "x"` | string (asciz appends a 0) |
| `.space n [, dolgu]` | n bytes of space (optional fill value) |
| `.align n` | round the address up to a multiple of n (instructions must be at even addresses) |

Errors are reported with line numbers. An out-of-range constant, an instruction at an odd address, a label defined twice and a branch that cannot reach its target are all assembly errors.

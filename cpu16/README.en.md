# CPU16

A 16-bit computer built entirely from 74HC chips, with its own instruction set and its own C compiler,
that you can inspect in 3D down to the transistor. It is also a teaching and experiment kit: over 14
experiments you build it on breadboards, starting from the clock board and ending with a snake game
written in C. The finished computer can take one of two routes: with PCBs (boards from KiCad) or
entirely on breadboards (one breadboard assembly per board, 149 breadboards, ribbon cable between
boards; [docs/breadboard.md](docs/breadboard.en.md)).

- Current stage: the simulation side is done, and the real boards come next. Details: [docs/roadmap.md](docs/roadmap.en.md).
- Experiment kit: [kit/README.md](kit/README.en.md) (13 experiments lead to the snake game; the 14th
  is an optional build-your-own-memory board).
- To read the docs in order: [reading path](../docs/README.en.md#path-a-understanding-cpu16).

## At a glance

| | |
|---|---|
| Processor | 16-bit, 8 registers (`r6` = SP, `r7` = LR), fixed 16-bit instructions, NZCV flags, byte-addressed 64 KB, memory-mapped I/O at `0xFF00–0xFFFF`. No hardware multiply/divide and no barrel shifter (done in software). |
| Control | Microcode (`micro/cpu16.ucode`, 32-bit control word), built from 74HC gates instead of stored in a ROM (generated by `board/kontrol.ts`). ≈ 5 clock cycles per instruction on average. |
| CPU board | 210 chips: register file, ALU (4 × 74HC283), PC, MAR, IR, flags, control unit; 39 LEDs and 26 bar graph displays for debugging, the register contents included ([kartlar.md](docs/kartlar.en.md)) |
| Motherboard | CPU + 6 boards, 460 chips in total: clock and reset (10), memory (34: 32 KB EEPROM + 128 KB RAM, bank registers), cache (46: 2 KB, wait states, counters), I/O (65: UART, PS/2, timer, interrupts), video (73: VGA 640 × 480, 80 × 30 text, 16 colors), build your own memory (22: 16 bytes, teaching board) |
| Parts | only common 7400-series logic and two memory chips (62256 SRAM, 28C256 EEPROM) |
| Software | as16 assembler, cc16 C compiler and libc16, BIOS (monitor, Intel HEX bootloader), Web IDE |
| Speed | the first real board targets 1 MHz (8 MHz oscillator); in simulation the motherboard model counts 4 MHz |

**Golden model:** the emulator under `emu/` defines correct behavior. The microcode model, the
gate-level boards and the real boards must run the same programs and match the emulator in lockstep;
the tests check this on every instruction.

**Schematic = code:** the boards are defined in code in `board/*.ts`. The gate-level simulation, the 3D
view in Silikon3D, the KiCad schematics (`kicad/`), the BOM, the connection tables in the experiment
guides and the build guides are generated from this definition.

## Commands

Everything runs from the repository root (in Docker, `docker compose run --rm cli` instead of `npm run`).

```sh
# programs
npm run cpu16 -- run cpu16/programs/hello.s          # assemble, run in the reference emulator (--trace: instruction by instruction)
npm run cpu16 -- asm cpu16/programs/fib.s -o fib.bin --list   # as16: .bin or Intel HEX (.hex), listing
npm run cpu16 -- dis fib.bin                         # disassemble a binary file
npm run cpu16 -- cc cpu16/programs/c/hello.c --run   # compile C, run it in the emulator
npm run cpu16 -- cc --hedef bios cpu16/bios/ornekler/yilan.c -o yilan.s   # C → assembly that runs on the BIOS
npm run cpu16 -- cc cpu16/bios/ornekler/selam.c --hedef bios --run        # on the motherboard model: BIOS + G 4000

# motherboard and EEPROM images
npm run cpu16 -- machine                             # motherboard + BIOS, UART connected to the terminal (exit: Ctrl-])
npm run cpu16 -- machine program.s                   # load the program into RAM through the bootloader and run it (.c works too)
npm run cpu16 -- cc --hedef bios cpu16/bios/ornekler/kalbur.c --run        # C example on motherboard + BIOS
npm run cpu16 -- machine cpu16/kit/programlar/bellek-deneme.s --rom --led # test program without the BIOS, FF00 LEDs
npm run cpu16 -- bios -o bios.bin                    # 32 KB 28C256 image (bios.hex: BIOS bytes only)
npm run cpu16 -- charrom -o charrom.bin              # character ROM of the video board

# hardware
npm run cpu16 -- chips                               # parts library: gate and transistor counts
npm run cpu16 -- board                               # chip counts per board and ERC
npm run cpu16 -- board kicad                         # regenerate the KiCad schematics, symbols and BOMs
npm run cpu16 -- ucode cpu16/micro/cpu16.ucode       # compile the microcode, cycle counts of the routines
npm run cpu16 -- kontrol                             # after a microcode change: regenerate and check the control unit (74HC gates)
npm run cpu16 -- zamanlama --anakart                 # static timing analysis from the schematic

# experiment kit, build guides, real board
npm run cpu16 -- kit                                 # generate the automatic sections of the experiment guides
npm run cpu16 -- kurulum hepsi                       # build guides (HTML + PDF): wire list, chip cards, handbook
npm run cpu16 -- breadboard                          # breadboard assemblies: dimensions, power, check of the connections against the netlist
npm run cpu16 -- breadboard-belge hepsi              # breadboard build guides (HTML + PDF): one assembly per board + index
npm run cpu16 -- mimari [cpu|makine|hesap|hepsi] [-o dir]   # block diagrams as SVG (without a directory: docs/img/ and hesap8/docs/img/)
npm run cpu16 -- kart-testi --port /dev/ttyUSB0      # compare the real board with the simulator over UART

npx vitest run cpu16                                 # CPU16 tests
```

All the options of the commands are in the comments at the top of `tools/cli.ts`, `tools/cc.ts`,
`tools/hw.ts` and `tools/machine-cli.ts`.

## Folders

| Folder | Contents |
|---|---|
| `docs/` | design docs (table above) |
| `emu/` | reference emulator (`cpu.ts`, golden model), disassembler, the motherboard model `Machine` and its devices |
| `asm/` | as16 assembler, Intel HEX |
| `micro/` | microcode source (`cpu16.ucode`), microcode compiler, clock cycle model; `cpu16-ucode.ts` is generated |
| `chips/` | 74HC parts library: gate model, datasheet table, CMOS transistor expansion, KiCad symbol; gate-level simulator `logic.ts` |
| `board/` | boards as code: CPU, clock, memory, cache, I/O, video, build your own memory, programmer; ERC, timing analysis, layout, KiCad output |
| `kicad/` | generated KiCad projects and BOMs, one folder per board (`hesap/`: the 8-bit calculator); never edited by hand |
| `bios/` | BIOS (`bios.s`), image, bootloader client, board test; `ornekler/` programs that run on the BIOS, `testler/` board test programs |
| `cc/`, `lib/` | cc16 C compiler; crt0, rt, libc16 and headers (`lib/include/`), BIOS target (`lib/hedef/bios/`) |
| `programs/` | examples that run in flat memory: assembly (hello, fib, add32, bubble, irq), `merhaba.c`; cc16 examples under `c/` |
| `kit/` | experiment guides, images, programs for the experiments that come before the BIOS (`programlar/`) |
| `kurulum/` | build guide generator; output in `kurulum/cikti/` (not committed) |
| `mimari/` | architecture (block) diagrams: layout (`cpu.ts`, `makine.ts`; the calculator's is `hesap8/mimari.ts`), content from the circuit and netlist check (`model.ts`, `denetim.ts`), drawing (`cizim.ts`, `agac.ts`), SVG and doc page |
| `breadboard/` | breadboard assemblies (layout, wires, ribbon cable, power), generated data (`veri/`), document generator; output in `breadboard/cikti/` (not committed). The shared engine is in `board/breadboard/` |
| `programlayici/` | Arduino Nano + 2 × 74HC595 EEPROM programmer (`.ino`) and `yaz.py` |
| `video/` | character ROM (8 × 16 font) |
| `tools/` | `npm run cpu16` commands |
| `tests/` | vitest tests |

The CPU16 sections inside Silikon3D live under `src/cpu16/` (workbench, Web IDE, Web Serial),
`src/board3d/` (board 3D view) and `src/mimari/` (block diagrams); all of them use the code in this
folder directly.
